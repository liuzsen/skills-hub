# Skills 分发平台

## 产品与技术边界

平台用于团队在社交平台宣传、站外售卖 skill 后，通过兑换码交付内容。首版不接入支付，不建设购物车、订单或自动发货。

部署目标为 `skills.zsen.top`，使用 Cloudflare；前端使用 React，后端使用 Rust，数据库和对象存储采用 Cloudflare 免费额度内的服务。

界面参考 GitHub，提供简洁的文件展示、文本文件浏览、README 渲染和 ZIP 下载。

## 公开目录与受限详情

**公开列表**：任何人（包括游客）均可访问的 skill 目录，展示名称、一句话简介、标签和更新时间。

**详情查看权**：访问某个 skill 的详情、文件树、README 和所有文本文件内容的权限。未获授权时，详情入口提示登录或输入兑换码，不返回受限内容。

**下载权**：下载某个 skill 的 ZIP 的权限，包含该 skill 的详情查看权。

获得详情查看权后，不额外限制文本文件的浏览或复制；付费下载不承担阻止手工复制内容的承诺。

## 账号与管理员授权

面向中国大陆用户，首版仅使用邮箱验证码注册和登录；首次验证自动注册，不维护密码。

管理员可分别向注册用户授予：

- **查看全部**：查看所有 skill 的详情和文本，不授予 ZIP 下载权。
- **下载全部**：下载所有 skill，包含查看全部权限。
- **上传/编辑**：创建和修改所有 skill，包含查看全部权限，不包含下载全部权限。

普通用户通过兑换码取得对应 skill 的权限，而非全部 skill 的权限。

## 兑换码与交付

**兑换码**：管理员创建、绑定特定 skill、在站外出售后交付给购买者的凭证。每个兑换码最多绑定一个账号，绑定后不可供其他账号使用。

注册用户绑定兑换码后，长期拥有对应 skill 的详情查看权和无限次下载权，包含后续更新。首版仅提供最新版本下载，不提供历史版本选择。

游客可凭兑换码领取一次有效期为 10 分钟的访问与下载凭证。窗口内可查看对应 skill 的详情和文本，并重试 ZIP 下载；窗口到期后不能再次领取游客凭证。

游客额度归属于兑换码，不按浏览器或 IP 计数。“一次下载”指一次领取凭证的机会，不是一次 HTTP 请求或一次完整文件保存。

游客领取凭证后，无论凭证是否过期，该兑换码仍可绑定一个账号，取得长期查看权和无限次下载权。绑定后不再提供游客领取。
