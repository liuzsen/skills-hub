# UI

## 视觉与交互

视觉可以丰富，文案应当精简。接受简单页面，禁止介绍、宣传、泛泛的免责声明或重复标题填满空间。文案只补足用户做决定、理解结果或恢复错误所缺的信息，不替直观的操作重复作解释。

减少成功反馈，结果已经可见时不重复通知。

保持布局稳定。加载、校验、错误反馈等临时状态不应挤动内容或移动操作目标，避免突然插入提示块造成布局跳动。避免滚动条出现、消失引起页面宽度变化与闪动。

## 技术栈

React/Vue 项目 TypeScript + Vite、Tailwind CSS、shadcn/ui。

## 实现

优先复用项目已有组件。采用 shadcn-vue 或 shadcn/ui 的项目优先使用其组件；需要自定外观的复杂交互，Vue 优先使用 Reka UI，React 复用项目已有的无样式原语，不自行重写焦点、键盘与关闭行为。

布局与局部视觉优先 Tailwind，复杂选择器、动画或 CSS 更清楚的样式使用局部 CSS。

全局样式只承载主题 token、字体、reset 与基础样式。页面布局、组件状态与局部覆盖归组件，不堆积跨组件选择器，不从外部穿透组件内部结构。
