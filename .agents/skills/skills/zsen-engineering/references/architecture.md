# 架构

## 语义归属 × 责任

按两条轴组织源码：语义归属（横轴）回答“谁治理这里的规则与演化”，责任（纵轴）回答“这里承担什么决定”。

语义归属分为：

- **A**：单一所有者，拥有共同语言、不变量与演化责任。类似 bounded context。
- **A ∩ B**：双方共同治理的语言或承诺。共同使用、形状相同或跨域流程，不足以建立联合所有权。
- **System**：系统整体的外部承诺、入口与组装选择。
- **None**：无业务语义的通用技术机制，不吸收项目政策。

Rust 的责任与物理边界见 [Rust](./clean-rust.md)。不为不存在的职责建空层。

## 抽象与文件

port 用于隔离语义、责任与依赖，不取决于实现数量。删除无独立责任的转发，但不因边界代码薄就删除边界。

既有结构直接阻碍本次实现、破坏依赖方向或迫使新增 workaround 时，将最小相邻重构纳入计划，延缓代码腐化。
